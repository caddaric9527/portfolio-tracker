投资组合收益统计 · 全新安装指南
版本 2026.11.15
================================================

本指南只有一条路径：在一台干净的设备上从零装好。
项目不提供升级包、不提供数据迁移工具。换版本 = 拿新代码重新装一遍，
数据用 JSON 备份搬过去（见第六节）。


一、前提
  设备已安装 Docker（含 docker compose 插件）
    飞牛 fnOS   应用中心 → Docker
    群晖 DSM    套件中心 → Container Manager
    普通 Linux  docker-ce + docker-compose-plugin
  不需要预装 Node.js，镜像里自带。
  全新安装要求目录里没有 data/、没有名为 portfolio 的容器。


二、三步装好
  1) 取代码
     mkdir -p /vol1/1000/docker
     cd /vol1/1000/docker
     git clone https://github.com/caddaric9527/portfolio-tracker.git portfolio

     没有 git 或仓库是私有的，就上传 zip 再解压：
     sudo unzip -o portfolio-tracker-main.zip -d portfolio

     进目录能看到 Dockerfile、docker-compose.yml、server、public 即为正确，
     不要多出一层同名文件夹。node_modules 与 data 都不需要带。

  2) 一条命令安装
     cd portfolio
     sudo bash deploy.sh

     脚本流程：环境检测 → 全新环境校验 → 生成随机密码 → 构建镜像
               → 启动容器 → 轮询健康检查 → 六段自检
     首次约 1~3 分钟，主要时间花在拉取 node:22-bookworm-slim。

  3) 记下密码并访问
     终端最后会打印：
        ✅ 安装完成，浏览器访问：http://192.168.x.x:8888
        🔑 已自动生成访问密码：xxxxxxxxxxxxxxxx
     浏览器打开该地址，输入密码，首次按 Ctrl+F5 强刷一次。
     进去是空白页（0 个组合），这是全新安装的正常状态。


三、deploy.sh 的三种模式
  sudo bash deploy.sh              全新安装（默认）
        检测到 data/portfolio.db 或已有 portfolio 容器时直接退出，
        只打印下面两个选项，绝不擅自覆盖数据。

  sudo bash deploy.sh --wipe       清空重装
        先把旧 data/ 改名成 data.bak.<时间戳> 保留，再空库重装。
        确认新装没问题后可自行删除备份目录。

  sudo bash deploy.sh --keep-data  只换代码、保留数据
        按当前代码重建镜像并启动，数据库原样不动。

  sudo bash deploy.sh --help       查看帮助


四、访问密码
  查看密码      grep AUTH_PASSWORD .env
  改成自己的    编辑 .env → AUTH_PASSWORD=你的密码 → sudo docker compose up -d
  改登录有效期  编辑 .env → AUTH_DAYS=7（天，默认 30）→ sudo docker compose up -d
  关闭密码认证  .env 里 AUTH_PASSWORD= 留空 → sudo docker compose up -d（不推荐）
  忘记密码      按「改成自己的」操作即可重置
  让所有设备强制重新登录
      sudo rm -f data/.auth-secret && sudo docker compose restart
      （签名密钥变了，所有旧登录凭证立即失效）

  安全说明
    - 密码只存在 .env 与容器环境变量里，不写入数据库
    - 登录凭证是 HttpOnly Cookie，前端 JS 读不到
    - 同一 IP 连续输错 5 次会锁定 10 分钟
    - 走的是 HTTP 明文，仅适合内网；如需外网访问请套 HTTPS（Nginx Proxy Manager 等）


五、开始使用
  1. 点「＋ 新增组合」，填名称、配置明细、定投方案、币种
  2. 每月点「＋ 录入本月数据」，选组合和月份，填
       投入本金（累计） / 当前市值
     系统自动算收益金额、收益率、本月盈亏
  3. 点「分享」可生成 1080 宽 PNG 图片
  4. 右上 ⚙ 可导出/导入 JSON 备份，右侧「退出」注销登录


六、数据与备份
  数据库文件  ./data/portfolio.db        （容器重建不丢，删目录才丢）
  备份方式 1  网页右上 ⚙ → 导出 JSON
  备份方式 2  cp data/portfolio.db 到别处（WAL 模式建议先 down 容器）
  迁移到新设备
     新设备走一遍「二、三步装好」，再用网页 ⚙ → 导入备份（合并/替换）。
     不需要拷数据库文件，也不需要拷任何旧版文件。
  恢复单个文件
     停容器 → 用备份覆盖 data/portfolio.db → 同时删掉 -shm 与 -wal → 启动


七、改端口
  改 .env 里的 HOST_PORT，例如 HOST_PORT=9000
  然后 sudo docker compose up -d


八、日常维护
  看状态    sudo docker compose ps
  看日志    sudo docker compose logs --tail=50
  重启      sudo docker compose restart
  停止      sudo docker compose down
  自检      sudo bash check-deploy.sh
  换代码    sudo bash deploy.sh --keep-data
            覆盖 server/ 或 public/ 后必须重建镜像：
            sudo docker compose up -d --build
            ⚠ restart 不会生效！public/ 和 server/ 是 COPY 进镜像的，
              只挂载了 data/。restart 只是重启进程，用的还是镜像里的旧文件。


九、彻底重置为刚装好的状态
  推荐      sudo bash deploy.sh --wipe
            旧库会备份成 data.bak.<时间戳>，然后空库重装
  手工版
      sudo docker compose down
      sudo mv data data.bak.$(date +%Y%m%d)
      sudo docker compose up -d


十、常见问题
  端口被占      改 .env 的 HOST_PORT 后 sudo docker compose up -d
  拉镜像慢      Docker → 设置 → 镜像仓库，加国内加速地址后重试
  权限不足      sudo usermod -aG docker $USER && newgrp docker
  构建失败      多为网络问题，重试；一直失败把日志发出来
  打不开页面    sudo bash check-deploy.sh 按 [FAIL] 项排查；
                确认防火墙放行端口；确认访问的是设备 IP
  一直提示密码错 确认 .env 里 AUTH_PASSWORD 与输入一致；被锁定就等 10 分钟，
                或 sudo docker compose restart 清空限流计数
  忘了密码      .env 里改一个新密码，sudo docker compose up -d 即可
  装完是空白页  正常，全新安装就是空库，先建组合


十一、卸载
  sudo docker compose down
  sudo docker rmi portfolio-tracker:2026.11.15
  sudo rm -rf ./data        # 数据会一起删除，先备份
